# Rebuilding the test environment

The optional scripts/provision-build-tools.py installs verified public tools into IW_BUILD_TOOLS (default: a sibling wallet-build-tools directory). Every archive URL and SHA-256 is committed in the script (no run-time manifests): Rust1.99.1, Gradle8.14.6, NDK28.2.13676358, build tools36, platform-tools r37.0.1, emulator 16740729, the API30 system image and the documented Temurin17 archive. To update a tool, change its URL and hash together in review. Archive symlink targets are restored as physical files if needed by this runtime. It imports only the runtime-managed CA into the build JDK when SSL_CERT_FILE is provided; it never changes wallet TLS trust. User signing keys/passwords stay separate. Standard builds can use an existing equivalent toolchain instead. Gradle dependencies are checked against android/gradle/verification-metadata.xml; after changing a dependency, regenerate it with `./gradlew --write-verification-metadata sha256` plus the release, unit-test and androidTest tasks, and review the diff.

Preserve source checkpoints before running long emulator tests. The earlier API36 emulator failed in SystemUI/network stack; use a disposable supported image and genuinely authenticate its own device PIN before Keystore tests. Never remove unlocked-device enforcement to make a test pass. The fixture APK is for a guarded emulator only and is never a user deliverable.
